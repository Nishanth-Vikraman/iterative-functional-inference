# Publication notes

This release contains the IFI implementation, configuration, tests, and project documentation. The project owner stated that the intended source contains no third-party material; authorship has not been independently verified. The inspected tasks and trajectory datasets are synthetically generated. Third-party packages are dependencies, not vendored copies; their own licenses apply.

Local checkpoints, run artifacts, datasets, caches and installed dependencies are excluded. As a result, commands that reference existing checkpoint paths require those checkpoints to be produced separately and may not run from this release alone. No project license is specified in the source material.

All 129 selected files were scanned for credential patterns, private-key markers, confidentiality markings, local user paths, and common external dataset references; none were detected. This automated check is not a guarantee that every sensitive detail or attribution issue has been found.
